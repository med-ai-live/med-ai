## What it is
A Health Operating System connecting patients, doctors, clinics, labs, pharmacies and the health system — with clinical decision support and patient safety at the core.

## Features (live)

**Clinical core**
- Patient records, triage with vitals + BMI, encounters, history, automatic SOAP
- Structured prescription + medication autocomplete + voice dictation
- **Clinical safety engine** (deterministic, auditable): allergies & cross-class allergy, drug interactions, pregnancy contraindications, duplication, diagnosis–conduct divergence — blocks finalization until reviewed
- Catalogs: lab, SUS/SIGTAP, imaging (CEDIP/TUSS)
- **Labs**: result ingestion + automatic abnormal-value flagging
- Vaccination card (doses, age)

**Specialized modules**
- **Prenatal** (auto gestational age / due date, obstetric history, serologies)
- **Gynecology / Climacteric** (menopause, symptoms, bone health)
- **Neonatology** (auto classification of prematurity / birth weight / APGAR, screenings, vitals with alerts, IV fluids)

**Platform**
- **Private AI** support (privacy-first) — explains exams, suggests conduct (always "review & sign")
- **Med Credits** (internal economy, Pix), **API Platform** (partner access)
- Telemedicine, scheduling, wearables (real time), Health Wallet (documents)
- Admin dashboard, document generator
- Open API for pharma & lab integration (B2B / B2B2C / B2G / marketplace)

**Compliance (LGPD)**
- Consent records, audit trail, role-based access, patient data behind authentication
